Progetto 01 / Architettura implementata

Come viene distribuito il portfolio

Route 53 risolve il dominio verso CloudFront. CloudFront termina HTTPS con un certificato ACM e recupera i file dal bucket S3 privato tramite OAC.

Browser → CloudFront · HTTPS → S3 privato · OAC

CloudFormation definisce l'infrastruttura. La pipeline usa GitHub Actions e un ruolo IAM assunto tramite OIDC, senza access key nei secrets.
